## 🎯 Habit Tracker App

A beautiful, modern habit tracker application built with React and Supabase. Track your daily habits, build streaks, and achieve your goals!

### 🚀 Getting Started

Navigate to the `habit-tracker` directory for the full application:

```bash
cd habit-tracker
```

See the [habit-tracker/README.md](habit-tracker/README.md) for detailed setup instructions, features, and documentation.

### ✨ Features

- 📝 Create & manage habits with custom icons and colors
- ✅ Daily tracking with streak counters
- 📊 Statistics dashboard with progress visualization
- 🎨 Beautiful, modern UI with smooth animations
- 💾 Cloud sync with Supabase backend
